# DFW Flea Markets

A directory of flea markets across the Dallas–Fort Worth area, with
city-level landing pages, maps, and search-indexed listings.

**Live:** https://dfwfleamarkets.com

## Overview

Flea market information in DFW is scattered across outdated pages and
social posts. This site consolidates it into a single searchable
directory with accurate location data.

## Stack

Next.js · Supabase (PostgreSQL) · Vercel · Google Maps API

## What's in here

- Dynamic city landing pages generated from the database
- PostgreSQL schema designed for market listings and locations
- JSON-LD LocalBusiness structured data, sitemap, and robots.txt
  for search indexing
- Google Maps integration for location display
- Deployed to production on Vercel with a custom domain
